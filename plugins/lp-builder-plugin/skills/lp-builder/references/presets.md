# プリセット（配色＋構成レシピ）— 正本

5つのトーンの LP を、そのまま写せる形にしたもの。**色だけ差し替えると「同じLPの色違い」に見える**ので、プリセット＝配色＋骨格（章順・面のリズム）＋部品の形、をセットで選ぶ。JSON は `examples/catalog/<preset>.json`（章単位でコピーして文言を差し替える。styles は変えない）。

## 選び方（ヒアリングシート #4 ゴール・#7 トーンから推論し、4〜5択＋おすすめ印で提示）

| ゴール / 業種の手がかり | おすすめ |
|---|---|
| (A) LINE登録・無料特典・イベント告知。ポップ・親しみやすい | 橙×緑 |
| (D) 高額講座・コンサル・士業。信頼・高級 | 紺×金 |
| 食・工芸・ウェルネス・手仕事。温かい | 茶×金 |
| 武道・和文化・職人。強い・意志 | 黒×朱 |
| オンライン講座・スキル系・若年向け。フレッシュ・テック | 黄×青 |

提示は文字情報で行う（Claude Desktop でも読めるように）: プリセット名・印象・想定業種・主要3色の HEX と HSL・骨格の一行。ブランド色の指定があれば、最も近いプリセットの `brand` / `accent` だけをその色に差し替える（面の明度関係は保つ）。トーンが合わない組み合わせ（例: 高額講座にポップ）は推奨から外し、理由を一言添える。

**(B) 告知・イベント／(C) 即決販売の場合**: 業種・トーンで骨格プリセットを選び、日程章（B・`schedule`）と料金カード＋申込ボタン章（C）は catalog に無いので `best-practices.md` の原則と `content-schema.md` で新規に組む（C の料金カードは `card_center` の形＝白カード・上端4px罫線・価格48px・箇条書き・塗りボタン）。

## 部品名の意味

- ヒーロー: `dark_center`=ダーク帯・中央 / `light_split`=白地・左文右画像＋実績ミニ / `light_bigtype`=白地・大文字＋上端の太罫線 / `accent_band`=識別色ベタ / `centered_stack`=中央積み＋部分色見出し＋全幅画像＋実績ミニ（黄×青は左罫線型のミニ実績＋英字ラベル）
- 特徴: `cards3`=3列カード / `numbered_list`=番号リスト（カード無し） / `steps`=番号の丸（黄×青は四角）＋3列
- 数字: `dark_bar`=ダーク帯（数字は白/金属色。彩度の高い赤・橙は不可） / `inline_light`=明るい面・帯なし（ヒーロー直下なら上罫線で続き物） / 面が `識別色の帯` のときは深色文字（黄×青）
- 声: `cards3` / `single_quote`=大きな引用1本 / `two_quotes`=大きな引用2本（ダーク帯上は半透明白カード＋識別色の左罫線・引用符）
- 料金: `card_center` / `two_col`。**ゴールDでは料金カードの代わりに「無料相談でお話しすること」カード**（内容3〜4項目・料金は1行・ボタンは無料相談）
- FAQ: `left_rule`=アクセント左線3px・Q見出しブランド色 / `plain_divider`=罫線のみ / `left_rule_accent`=識別色の左罫線4px
- CTA帯: `dark_grad` / `surface_light`（帯を作らない） / `accent_band`=ブランド色ベタ＋白ボタン

## 共通の型（全プリセット）

- 主CTA は D＝3箇所（ヒーロー・中盤・CTA帯）/ A＝2箇所（ヒーロー・CTA帯）。いずれも**同じ文言・同じ遷移先**。補助動線はテキストリンク型（背景なし・ブランド色文字・「→」・幅自動）
- 実績ミニ3点（ヒーロー内）: 数字 24px 太字＋単位 14px 太字、ラベル 12px。数字バー: 48px 太字＋単位 20px、縦罫線、出典注記
- 入れ子セクションの背景は必ず `hsla(0, 0%, 100%, 0)` を明示（既定は白）
- 仮画像はプレースホルダ素材 `https://mosh.jp/images/522545e4fca64345a420e594e1b2f6c1`（16:10）。公開前に必ず差し替える
- フッター: 特商法/プライバシーポリシー行＋`© {西暦} {事業者名}`、ダーク地
