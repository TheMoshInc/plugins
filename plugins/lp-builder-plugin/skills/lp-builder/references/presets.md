# プリセット（配色＋構成レシピ）— 正本

6つのトーンの LP を、そのまま写せる形にしたもの。**色だけ差し替えると「同じLPの色違い」に見える**ので、プリセット＝配色＋骨格（章順・面のリズム）＋部品の形、をセットで選ぶ。JSON は `examples/catalog/<preset>.json`（章単位でコピーして文言を差し替える。styles は変えない）。

## 選び方（ヒアリングシート #4 ゴール・#7 トーンから推論し、4〜5択＋おすすめ印で提示）

| ゴール / 業種の手がかり | おすすめ |
|---|---|
| (A) LINE登録・イベント告知。ポップ・親しみやすい | 橙×緑 |
| (A) 無料PDF・動画・テンプレの**特典配布型**（オプトイン）。SNS集客・情報発信系 | 紫×マゼンタ |
| (D) 高額講座・コンサル・士業。信頼・高級 | 紺×金 |
| 食・工芸・ウェルネス・手仕事。温かい | 茶×金 |
| 武道・和文化・職人。強い・意志 | 黒×朱 |
| オンライン講座・スキル系・若年向け。フレッシュ・テック | 黄×青 |

提示は文字情報で行う（Claude Desktop でも読めるように）: プリセット名・印象・想定業種・主要3色の HEX と HSL・骨格の一行。ブランド色の指定があれば、**「ブランド色からパレットを起こす」の手順で8ロールを導出する**（`brand` だけ差し替えて淡い面・文字・深色をもとのプリセットのまま残すと色相が濁る）。トーンが合わない組み合わせ（例: 高額講座にポップ）は推奨から外し、理由を一言添える。

**(B) 告知・イベント／(C) 即決販売の場合**: 業種・トーンで骨格プリセットを選び、日程章（B・`schedule`）と料金カード＋申込ボタン章（C）は catalog に無いので `best-practices.md` の原則と `content-schema.md` で新規に組む（C の料金カードは `card_center` の形＝白カード・上端4px罫線・価格48px・箇条書き・塗りボタン）。

## ブランド色からパレットを起こす（指定色があるとき／7本目を作るとき）

プリセットを選ばせるだけで済むのは、ユーザーに色の指定が無い場合。**ブランド色を指定されたら、その色から8ロールを導出する**。「近いプリセットの brand を差し替えるだけ」で済ませると、淡い面・文字・深色がもとのプリセットの色相のまま残って濁る。

### 手順1: 8ロールを HSL で導出する

ブランド色を `hsl(H, S, L)` として、残りを機械的に決める（**既存6本すべてがこの範囲に収まっている**ことを実測で確認済み）。

| ロール | 決め方 | 実測レンジ |
|---|---|---|
| 地 | `#ffffff` 固定 | — |
| 淡い面 | 同系色相 `hsl(H±15, 35〜45%, 96〜97%)`。**ブランドの彩度が80%以上なら無彩色寄り** `hsl(H, 0〜15%, 95〜96%)` に逃がす（高彩度色は薄めても色が残って濁るため） | L95〜97 |
| 文字 | 同系色相 `hsl(H±5, 20〜37%, 19〜23%)`。**純黒 `#000000` は使わない**。ブランドが高彩度の暖色（赤・橙）なら無彩色 `hsl(0, 0%, 11〜13%)` | L19〜23 |
| 補助文字 | 文字と同色相で彩度を落とす `hsl(H±5, 11〜15%, 37〜44%)` | L37〜44 |
| 深色（ダーク帯・フッター） | 同色相のまま暗く `hsl(H±5, 25〜89%, 18〜21%)` | L18〜21 |
| アクセント・識別色 | **色相を離す**（手順2）。明度は `L 40〜58%` | L40〜58 |
| 主CTA | 識別色を地に。黄・ライム等の高明度色なら**載せる文字を深色**にする | — |

- **明度の順序を必ず守る**: 地(100) > 淡い面(95〜97) > 補助文字(37〜44) > 文字(19〜23) ≒ 深色(18〜21)。この順序が崩れると、面と文字の関係が壊れて一気に素人っぽくなる
- ユーザー指定色は**そのまま使う**（勝手に補正しない）。導出した他のロールだけを HEX で提示して確認を取る
- 導出後、「テキスト色と背景色のコントラスト」（`best-practices.md`）の禁則と数値基準を必ず通す

### 手順2: アクセントの色相差をトーンで決める

| 狙うトーン | ブランドとの色相差 | 既存の例 |
|---|---|---|
| 信頼・高級 | **補色（150〜180度）** に金属色（金・シルバー）を当てる | 紺×金（178度） |
| 温かい・手仕事 | **アナログ（0〜30度）** でまとめる | 茶×金（22度） |
| フレッシュ・ポップ | **対照（90〜150度）** | 黄×青（149度）／橙×緑（149度） |
| 強い・和・意志 | **モノクロマティック**（無彩色＋1色だけ） | 黒×朱（0度） |
| 軽快・SNS的 | **中差（30〜90度）** にしてグラデにする | 紫×マゼンタ（82度） |

- **主CTAの色は、ブランドからもアクセントからも90度以上離す**と、クリック対象が色だけで一意に識別できる（紫×マゼンタの LINE緑＝ブランドから98度）。離せない場合は明度差（濃いブランド面＋明るいCTA）で代替する
- 色相差が30度未満（アナログ）のときは、明度差を20以上つけないと2色が同じ色に見える

## 部品名の意味

- ヒーロー: `dark_center`=ダーク帯・中央 / `light_split`=白地・左文右画像＋実績ミニ / `light_split_bgimage`=`light_split` の背景を実写真化したもの（`section` の `attributes.background` に写真＋左カラムだけ**片側パネル**（`hsla` で自ブランドの淡い面色＋透過0.88〜0.95。`best-practices.md`「スクリム・パネル・薄い面は別物」）を重ねて文字を包む。右カラムは写真をそのまま見せる。顔など主要被写体がパネルの側に来ないよう画像を明示的にクロップする） / `dark_center_bgimage`=`dark_center` の背景を実写真化＋**全面スクリム（暗幕 α0.55〜0.70）**で包んだもの / `light_bigtype`=白地・大文字＋上端の太罫線 / `accent_band`=識別色ベタ / `centered_stack`=中央積み＋部分色見出し＋全幅画像＋実績ミニ（黄×青は左罫線型のミニ実績＋英字ラベル）
- 特徴: `cards3`=3列カード / `numbered_list`=番号リスト（カード無し） / `steps`=番号の丸（黄×青は四角）＋3列
- 数字: `stat_cards_invert`＝識別色のベタ面の上にブランド色のカード3枚を置き、数字を識別色48px・ラベルを淡色14pxで入れる図地反転型（黄×青の `sec-02-proof` がこの形）。`dark_bar`=ダーク帯（数字は白/金属色。彩度の高い赤・橙は不可） / `inline_light`=明るい面・帯なし（ヒーロー直下なら上罫線で続き物） / 面が `識別色の帯` のときは深色文字（黄×青）

## 共通の型（全プリセット）

- 主CTA は D＝3箇所（ヒーロー・中盤・CTA帯）/ A＝2箇所（ヒーロー・CTA帯）。いずれも**同じ文言・同じ遷移先**。補助動線はテキストリンク型（背景なし・ブランド色文字・「→」・幅自動）
- 実績ミニ**2〜3点**（ヒーロー内）: 数字 24px 太字＋単位 14px 太字、ラベル 12px。**枠は「実績」に使う**（人数・率・満足度・期間実績・もらえる分量まで）。「登録30秒」のような**所要時間・手続きの手軽さはコストの説明であって実績ではない**ので、CTA下の注記に書く。実績が2つしか無いなら**2点でよい**（3点に揃えるために仕様やコストを混ぜない）。数字バー: 48px 太字＋単位 20px、縦罫線、出典注記
- **改行はスマホ基準**（SP 375px・本文領域335px / PC 1080px・本文領域960px）。SPで①孤立行を作らない②語中で割らない③階層を壊さない、を満たす。打ち手は 文言短縮 → `hardBreak` → SPのfontSizeを1段下げる → 枠を広げる の順。字数表は `best-practices.md`「改行はスマホ基準で決める」が正
- 写真＋テキストの2カラムは**写真30%／テキスト66〜70%**（36pxの見出しを置く側は58%以上）。写真カラムを38%以上にすると縦長写真のときに高さが揃わず、テキスト側の下に大きな空白が出る
- **面とカードの明度差は6以上**（HSL の L）。淡い面は L91〜95 に置く（白との差 5〜9）。差が3〜4だと実機ではカードの輪郭が見えない
- **カードを中央に置くときは左右に透明のスペーサー列を入れる**（`display:flex` の子が1つだけだと左寄せになる。`margin` は使えない）。例: 20% / 60% / 20%
- 入れ子セクションの背景は必ず `hsla(0, 0%, 100%, 0)` を明示（既定は白）
