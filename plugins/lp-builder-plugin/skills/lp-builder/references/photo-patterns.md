# 写真・画像の見せ方（型の一覧）

実在55ページ・275枚の調査（先方調べ）から取り出した型。**画像スロットを「どう置くか」を章ごとに決める**ための語彙表。役割（Hero/Problem/Solution/Trust）と枚数の目安は `best-practices.md`「画像点数の目安」「画像の置き方」が正で、ここは置き方の引き出し。

**この一覧に「おすすめ」を付けない。** 付けると、どの LP も同じ作りに寄る。毎回、そのクリエイターの素材・役割・プリセットから選ぶ（ゴール種別・プリセットの「おすすめ印」はヒアリング用で別物）。型は増やしてよい。

## 使い方

1. **ページ全体の形を1つ決める**: 角丸は `presets.md` の値に揃えて1種類、写真の縦横比は2種類まで（縦横比は `image` の `imageClip` の枠で揃えられる＝`content-schema.md`「`image` の切り抜き」）。**大きさ（幅）に強弱を付けるのは `best-practices.md`「写真は強弱を付ける」どおり。形は揃え、大きさで強弱を付ける**
2. **章ごとに型を選ぶ**（下の表）。構成案の「レイアウト型」列（`section-plan.md`）には、番号ではなく**型の名前**（例「本文に挟む証拠写真」）で書く（番号はユーザーに見せない）。**括弧内の専門語（スタッガード・メイソンリー・ブリード・カルーセル・モザイク等）は書かず、平易な言い方にする**（例「互い違いに浮かせる」「高さ違いの2列」「片側を画面外へ抜く2枚」）。枚数は足す理由にしない（目安は `best-practices.md`）
3. **例外は1ページに1か所**: アーチ・円・切り抜き・額装などの特別な形は、ヒーローか最後の章に置く。形がすべて揃うページと、1か所だけ崩すページは成立する。**あちこち崩れたページは、写真が良くても素人っぽく見える**
4. **素材が足りない枠は F 型（写真を使わない）を選択肢に**出す。イメージ写真で埋めない（`hearing-sheet.md` #7 の3択と同じ）

**縦横比を揃える規則との関係**: `best-practices.md`「配置のリズム」は「横並びの画像は縦横比を揃える」。**B1・C3 はその意図的な例外**で、使い方3の「例外は1ページに1か所」の枠を使う。B1・C3 は本文の章に置いてよい（アーチなどの特別な形はヒーローか最後の章、と置き場所が違う）が、**枠は共有**するので、B1・C3・アーチなどの特別な形は、同じページでどれか1つだけ。ほかの章では縦横比を揃える。B3 は幅だけを変え、縦横比は揃える。

**「LP機能」列の記号**: ○＝このスキルの許可プロパティ（`content-schema.md`）で作れる／△＝加工済みの画像を用意する、または代替が要る／×＝作れない（代替を先に出す）。写真の上に文字を重ねる型は `content-schema.md`「背景画像の上に文字を重ねる（構造レシピ）」。

## A. 冒頭（ヒーロー）

| # | 型 | 形 | 文字 | LP機能 |
|---|---|---|---|---|
| A1 | **全幅の写真** | 画面の端まで・直角・縦1〜2画面 | 白抜きで重ねる（暗くする） | ○ 背景画像の section＋入れ子のスクリム |
| A2 | **アーチ・弧で切る** | 上辺だけ弧の縦長。左右に余白 | 写真の外（上） | △ マスク済みの画像を作って置く |
| A3 | **写真モザイク（端で見切る）** | 中央に大＋左右に小を画面端で切る | 写真の外 | ○ `display:flex` の行＋子 section の `width` を変える |
| A4 | **送りヒーロー（カルーセル）** | 複数枚＋停止ボタン・ドット | 画像に焼き込み | × 部品が新規作成不可。1枚に絞る |
| A5 | **文字は据え置き、写真だけ差し替え** | 背景だけ切り替わる | 固定 | × 動きの部品が無い |
| A6 | **お客様の投稿をヒーローに（@クレジット）** | 全幅＋左下に小さく @名 | 重ねる | ○ 許諾を取ってから |

## B. 本文の中の写真

| # | 型 | 形 | LP機能 |
|---|---|---|---|
| B1 | **片側ブリードの非対称ペア** | 2枚の幅・高さを変え、片方を画面外へ抜く | ○ 子 section の `width` で比を変える（端まで抜くのは `padding:0` の section）。**意図した不揃い＝例外枠**（下記） |
| B2 | **片角丸の写真＋隣に文字の面** | 写真の1コーナーだけ大きく丸める | △ **コーナー別の角丸は編集画面で直せない**（角丸は1つの数値のみ。`"0 80px 0 0"` のような複数値は編集で消える）。片角丸の形にした画像を用意して置く。**面を重ねる食い込みも不可**（隣に並べる） |
| B3 | **互い違いに浮かせる（スタッガード）** | 6〜8割幅を左右交互に | ○ 行ごとに透明スペーサー列（`width` %）で左右へ寄せる。写真の縦横比は揃える（幅だけ変える） |
| B4 | **本文に挟む証拠写真** | 見出し→本文→16:9写真、を反復 | ○ そのまま |
| B5 | **小さく置いて余白で見せる** | 画面幅の1/3・中央・直角 | ○ `image` の `width:"33%"`＋`layout.styles.textAlign:"center"` |
| B6 | **色面と写真の交互積み** | 写真（全幅）→色ベタ＋キャプション、を繰り返す | ○ 写真が少ないときに向く |
| B7 | **番号カウンター章（01／05）** | 章ごとに写真1枚＋大きい番号 | ○ 大きい数字の text＋image |
| B8 | **ずらし重ねの束** | 3枚を少しずつずらして重ねる | △ 重ねは負の余白が要る＝1枚の画像に焼いて置く |
| B9 | **写真の上に白いカードを浮かべる** | 背景写真＋白いカードの中に縦長写真と本文 | ○ 背景画像の section＋内側の白い面（構造レシピ） |
