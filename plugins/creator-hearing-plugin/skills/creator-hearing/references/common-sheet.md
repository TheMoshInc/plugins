# 共通シート（3ブロック）

目的に関わらず、ほぼすべての「作る」前に必要な3ブロック。目的ごとの追加ブロックは、呼び出し元のスキルのシートを足す（`define-sheet.md`）。進め方・必須ルール・禁止は `SKILL.md` が正で、ここには再掲しない。

## 項目

| # | ブロック | 項目 | 区分 | 仮埋めの主な材料 |
|---|---|---|---|---|
| 1 | 商品・オファー | 商品名 / 価格 / 提供形式・期間 / 特典・保証・締切 / **含まれない物・追加費用**（あれば。無ければ「無し」と確認する）/ 選ばれる理由（競合・代替手段との差） | **必須** | 原稿があれば原稿 → スナップショット → `getCreatorProduct(s)` / `getCreatorProductPlans` で突合 |
| 2 | 顧客像 | 1人分の「状況・いま困っていること・いま使っている代替手段」（下記の合格基準） | **必須** | 商品説明・原稿から逆算 |
| 3 | 行動（CV）先 | 唯一の行動（申込 / 購入 / LINE登録 / 資料DL / 予約）と遷移先（MOSH のサービス・プラン、または外部 URL） | **必須** | 商品・プラン。無ければ要記入 |

- #1 の「含まれない物・追加費用」は、聞かないと出てこない。無ければ「無し」と**確認して**書く（空欄にしない）
- #3 は**1つ**に決める。複数の行動を混在させない（例: 無料相談と高額申込）。高額商品は相談への申込に一本化し、料金は見せるだけにする
- #3 は目的ごとに変わりうる。目的が変わって行動先が変わるときは、共通ブロックを書き換えず、その目的の追加ブロックに「#3（この目的の行動先）」を足す
- 番号は目的ごとに独立。呼び出し元のシートは #4 から足す

## 顧客像（#2）の合格基準

- **1人分**で、次の3点が**具体名詞**で書けていること: (a) 状況（職業・立場・ライフステージ）(b) いま困っていること (c) いま使っている代替手段（他サービス・独学・放置 等）
- 「30〜50代女性、幅広く」「起業したい人全般」は不合格。埋まっているが使えない
- 不合格・空欄のときは**書かせず、選ばせる**: 商品の価格・期間・約束（説明文）から逆算して顧客像候補を 2〜3 人分こしらえ、「どれが一番近いですか」と選択させる。選ばれたものを確定値にし、微調整だけ受ける

## 状態ラベル（定義と遷移）

| ラベル | 付ける条件 |
|---|---|
| `確認` | 調査（スナップショット・MCP・原稿）で埋まった。出典を添える（「原稿◯段落目」「商品」「スナップショット」。原稿のときは段落番号まで書く）。誤りがあれば直してもらう。「調べたが記載が無かった」という結果も、出典を添えて `確認` にできる（例: 保証: 記載なし（商品）） |
| `要記入` | 材料が無い。何を書けばよいかを1行で示す |
| `仮定` | 任意欄で材料が無く、仮置きした（そのまま進む） |
| `確定` | ユーザーが答えた（回答・選択・「これでよい」の肯定） |

- **材料が無い項目を `確認` にしない。**
- 遷移: `要記入` は、ユーザーが答えたら `確定`。`確認` は、ユーザーが答えず訂正も無ければ `確認` のまま有効（必須欄は `確認` か `確定` で埋まったとみなす）。ユーザーが直したら `確定`。`仮定` は、ユーザーが答えたら `確定`。任意欄の `要記入`（呼び出し元のシートで必ず聞くと決めた欄）は、回答が無いまま進むとき `仮定` に変えて保存する

## 提示フォーマット

冒頭に一言添える: 「下の表の『要記入』と、違っている『確認』だけ直してください。それ以外はそのまま進めて、次の段階で確認します」。

```
| # | 項目 | 内容 | 状態 |
|---|---|---|---|
| 1 | 選ばれる理由 | （材料なし）競合や独学と比べて何が違うか一言 | 要記入 |
| 1 | 含まれない物・追加費用 | （材料なし）教材費・更新料など、料金に含まれないものはありますか（無ければ「無し」） | 要記入 |
| 2 | 顧客像 | 候補A: 副業で◯◯を始めた会社員、初案件が取れず独学の限界 / 候補B: … / 候補C: … → どれが近いですか | 要記入 |
| 1 | 商品 | 「◯◯講座」12週間・98,000円・Zoom個別3回＋動画。特典: テンプレ集。保証: 記載なし（商品） | 確認 |
| 3 | 行動先 | 「◯◯講座」プランの申込（商品） | 確認 |
```

目的ごとの追加ブロックは、この表に続けて足す。`確認` は「商品の説明文から埋めました。違う所だけ直してください」のように1行でくくってよい。
