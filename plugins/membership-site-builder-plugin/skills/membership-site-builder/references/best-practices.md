# 会員サイトの組み立て方

## ID 参照の確認手順

書き込みの前に、使う ID を必ず取得ツールで確かめる。

| 使う ID | 確認手順 | 見つからないとき |
|---|---|---|
| 会員サイトの `id` | `getCreatorMembershipSites` でサイト名から特定する | 候補を挙げて選んでもらう。名前が近いだけで決めない |
| `folderId` | `getCreatorMembershipSiteFolders` でフォルダ名から特定する | 先にフォルダを作る（コンテンツはフォルダ無しには置けない） |
| `contentId` | `getCreatorMembershipSiteFolders` の `contents[].title` から特定する | 同名のコンテンツが複数あるときは、フォルダ名と公開状態を添えて選んでもらう |
| `tagIds` | `getCreatorMembershipSiteTags` でタグ名から特定する | 無いものだけ `postCreatorMembershipSiteTags` で作る |
| `assetIds` / `thumbnailAssetId` | 取得経路が無い | 新規作成では `[]` と `null` を渡す。既存コンテンツを更新するときは `getCreatorMembershipSiteContent` の値をそのまま使う |

## サイトを一から作るとき

1. **サイトを作る**（非公開で誕生する）
2. **フォルダを先に決める。** 会員が最初に見る並びになるため、名前と順番をユーザーと決めてから作る。並び替えるツールは無いので、**作る順番がそのまま並び順**になる
3. **コンテンツを 1 件ずつ作る。** 前の作成が返ってきてから次を呼ぶ
4. **全部そろってから公開する。** サイト・フォルダ・コンテンツの 3 つを公開にして初めて会員に見える

下書きのまま組み立てたいときは、フォルダもコンテンツも `isPublished: false` で作る。フォルダを公開のまま作ると、今後追加されるフォルダを自動で閲覧可にする設定の権限を持つ会員には、その時点で見えてしまう。

## フォルダの表示形式を選ぶ

| 形式 | 向いている中身 |
|---|---|
| カルーセル | 順番に見せたい少数のコンテンツ（最大 15 件表示） |
| リスト | 件数が多く、タイトルで探してもらいたいとき |
| タイル | サムネイルで選んでもらいたいとき（スマートフォンは 1 列で最大 10 件、PC は 4 列で最大 8 件） |

決められないと言われたら、件数から提案する（少数ならカルーセル、多いならリスト）。

## 動画・音声を含むとき

MCP から動画・音声を上げられないため、**作れるのは非公開の下書きまで**。次のように分けて進める。

1. タイトル・概要・本文・タグ・チャプターまでを `isPublished: false` で作る
2. ユーザーに「本体の動画（音声）の紐付けと公開は管理画面で行う」ことを伝える
3. 管理画面での作業が済んだあとに公開状態を確認したいと言われたら、`getCreatorMembershipSiteFolders` で読み戻す

チャプターは本体が無くても先に入れておける（`startTime` は秒数）。

## 記事コンテンツの本文

本文は Markdown として解釈されない。読みやすくするには次のようにする。

- 段落は改行で分ける（改行は段落として反映される）
- 見出しを付けたいときは、記号ではなく短い一文で区切る（`##` と書くとそのまま文字で出る）
- 箇条書きも記法が効かないため、`・` を行頭に置くなど文字で表現する
- 装飾や画像の差し込みが要るなら、管理画面のエディタで仕上げてもらう

## コンテンツが多いサイトを扱うとき

`getCreatorMembershipSiteFolders` はページングされず、全フォルダ・全コンテンツの概要を 1 回で返す。概要は 1 件あたり最大 10,000 文字になるため、コンテンツ数が多いサイトでは応答が大きくなる。

- 目的が決まっているなら、フォルダ名やタイトルで絞ってから提示する（全件をそのまま並べない）
- 本文が要るときだけ `getCreatorMembershipSiteContent` を呼ぶ（一覧には本文が入っていない）

## 似たコンテンツを増やすとき

`postCreatorMembershipSiteContentDuplicate` で複製してから書き換えるほうが、一から組み立てるより早く、チャプターとタグと本体の紐付けも引き継がれる。ただし次の 3 点は引き継がれないため、複製後に `patchCreatorMembershipSiteContent` で入れ直す。

- 予約公開・予約非公開・購入後◯日で公開
- コメントの受け付け（必ず無効になる）
- タイトル（「〈元のタイトル〉のコピー」になる）

## セルフレビューチェックリスト

書き込みの前に一度、保存して読み戻したあとにもう一度実行する。

| # | 確認項目 |
|---|---|
| 1 | 使った `folderId` / `tagIds` を取得ツールの結果から取ったか（推測していないか） |
| 2 | サイト設定の更新で、7 項目すべてを直前に読んだ値で埋めたか |
| 3 | `isFixedViewingOrder` を、ユーザーの依頼なしに `false` へ変えていないか |
| 4 | `chapters` / `assetIds` / `tagIds` を送るとき、現在値を含む配列全体にしたか |
| 5 | 公開しようとしているコンテンツの `isNotifyOnPublish` を確認し、通知の要否をユーザーに確かめたか |
| 6 | 動画・音声のコンテンツを `isPublished: false` で作り、管理画面での作業を案内したか |
| 7 | `scheduledPublishAt` と `visibleAfterPurchaseDays` が同時に入っていないか |
| 8 | 日時にタイムゾーンオフセットを付けたか |
| 9 | 削除の前に、対象の名前と消える範囲を提示して承認を得たか |
| 10 | 連続した作成・複製・移動を 1 件ずつ順に呼んだか |
| 11 | 提示する文面に生の内部 ID・`slug`・英字の設定値・JSON が入っていないか |
| 12 | 公開したつもりのコンテンツについて、サイトとフォルダも公開になっているか確認したか |
