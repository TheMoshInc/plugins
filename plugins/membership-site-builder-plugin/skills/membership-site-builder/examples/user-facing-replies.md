# 例: ユーザーへの返答の書き方（内部の値を出さない）

ツールの結果やこのスキルの説明には `id`・項目名（`linkedProductPlanCount` など）・英字の値が出てくるが、**ユーザーへの返答には 1 つも書かない**。下は実際に起きた漏れと、その直し方。

## 1. 対象を見つけたとき

- NG: 「ヨガ会員サイト」（id: 7）が見つかりました。
- NG: 「基礎レッスン」フォルダ（ID: 71）に追加します。
- OK: 「ヨガ会員サイト」が見つかりました。
- OK: 「基礎レッスン」フォルダに追加します。

名前の後ろに括弧で ID を添えない。同じ名前が複数あって区別が要るときは、作成日・中のコンテンツ数・公開状態など、ユーザーに見える情報で区別する。

## 2. できない理由を説明するとき

- NG: 「ヨガ会員サイト」は `linkedProductPlanCount` が 1 件あり、削除できません。
- OK: 「ヨガ会員サイト」は 1 件の商品プランで販売中のため、このままでは削除できません。先に商品側でこのサイトとの紐付けを外す必要があります。見えなくしたいだけなら非公開にする方法もあります（ただし購入済みの会員も見られなくなります）。

## 3. このスキルの規則を説明するとき

- NG: これは `unpublishAfterPurchaseDays`（購入後◯日で非公開）という設定にあたり、管理画面には設定欄がありません。
- OK: 「購入から◯日たったら見られなくする」設定は、管理画面からも設定できないため使えません。代わりに、決まった日時で非公開にするか、プランの閲覧期間を設定する方法があります。

このスキルの文章は作業者向けに項目名で書いてある。ユーザーに伝えるときは、項目名を取り除いて、画面での言い方・やりたいことの言い方に置き換える。

## 送る前の確認

返答を送る前に、本文に次が残っていないかを見る。

- `id`・`ID`・数字だけの識別子（`7`、`71` など）
- バッククォートで囲んだ英字の項目名（`isPublished`・`thumbnailAssetId` など）
- 英字の設定値（`video`・`folderView`・`#0369A1` など。色は「ブルー」のように日本語にする）
