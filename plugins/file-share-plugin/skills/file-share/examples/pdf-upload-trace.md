# 完全トレース: PDF を1本アップロードして共有URLを渡す

手元の PDF を新規登録して共有URLを伝えるまでの1往復。**承認を1回だけ取り、承認後は止まらずに通す**形（アップロード先URLが15分で失効するため）と、提示規約の適用例を兼ねる。値はすべて架空。

---

## ユーザー

> `~/Documents/受講の手引き_2026冬.pdf` をファイル共有に追加して、共有URL教えて

---

## アシスタント（実行前・承認を求める）

送るファイルの形式とサイズを先に確認する。

```bash
$ file --mime-type -b ~/Documents/受講の手引き_2026冬.pdf
application/pdf
$ wc -c < ~/Documents/受講の手引き_2026冬.pdf
4194304
```

> 以下の内容でファイル共有に追加してよいですか。**まだ何も保存していません。**
>
> - ファイル: 受講の手引き_2026冬.pdf（PDF・約4.0MB）
> - タイトル: 「受講の手引き 2026冬」（ファイル名から補いました。変えたい場合は教えてください）
>
> 追加すると共有URLが1本発行されます。**この共有URLは、URLを知っている人なら誰でも開けます**（購入者だけに限定する設定はありません）。配布をやめたいときは共有リンクを削除します（削除すればこのURLは開けなくなります）。

**ここで止まる。** 承認前に枠の発行にも進まない（発行から15分で失効するため、承認後にまとめて通す）。

---

## ユーザー

> それでOK

---

## アシスタント（実行）

### 1. アップロード枠を発行

`postCreatorMaterialFileUpload`

```json
{ "bodyParams": {
  "fileName": "受講の手引き_2026冬.pdf",
  "mimeType": "application/pdf",
  "fileSizeBytes": 4194304
} }
```

返り: `moshMediaId: "media-8f2c..."` / `uploadUrl: "https://<署名付きURL>"`

### 2. 実体を送る（MCP は代行しない）

```bash
$ curl -sS -X PUT --fail-with-body \
    -H "Content-Type: application/pdf" \
    --upload-file ~/Documents/受講の手引き_2026冬.pdf \
    "https://<署名付きURL>"
```

### 3. 変換完了を待ってから登録

送信の完了と MOSH 側で使える状態になるのは同時ではないので、数秒待ってから登録する。

`postCreatorMaterialFile`

```json
{ "bodyParams": {
  "title": "受講の手引き 2026冬",
  "moshMediaId": "media-8f2c...",
  "fileSizeBytes": 4194304
} }
```

返り: 素材 ID `912`

### 4. 共有リンクを確認（発行し直さない）

登録時に共有リンクが1本自動で発行されるので、`getCreatorMaterialContentLinks`（素材 ID `912`）で `slug` を取り、`https://mosh.jp/materials/<slug>` を組み立てる。**新しく発行する必要はない。**

> このトレースは**本番環境に接続している前提**。ホストは接続先の環境で変わるので決め打ちしない（SKILL.md §B）。

返り: `slug: "7c1e...-...-...-...-...."`（期限なし）

> 「受講の手引き 2026冬」をファイル共有に**追加しました**。共有URLはこちらです。
>
> https://mosh.jp/materials/7c1e...-...-...-...-....
>
> - このURLを知っている人は誰でも開けます（期限は設定できないので、配布をやめたいときはお知らせください。共有リンクを削除すれば開けなくなります）
> - PDF はブラウザで表示され、相手側で保存もできます

## この例が示していること

| 論点 | この例での扱い |
|---|---|
| 承認のタイミング | **枠の発行より前に1回だけ**。承認後は枠発行 → 送信 → 登録を止めずに通す（15分の失効を避ける） |
| サイズ・形式 | 推測せず `wc -c` / `file` で実測してから枠を発行する |
| 補った項目 | タイトルをファイル名から作ったことを明示している |
| 変換待ち | 送信直後に登録せず、待ってから登録する（拒否されたら同じ値で登録だけ再試行） |
| ホスト | 接続している環境に合わせる。決め打ちしない（この例は本番前提） |
| 共有リンク | 登録時に自動発行されたものを使い、重複発行しない |
| 本体URL | ユーザーに渡すのは共有URLだけ。一覧のサムネイルURLも詳細取得の本体URLも配布に使わない（MCP から失効させる経路が無い） |
| 期限 | 「期限は設定できない」と正直に伝え、代わりの運用（リンク削除）を示す |
| 提示規約 | 「素材」「moshMediaId」「slug」「READY」等の内部語をユーザー向け文面に出していない。完了形は実際にツールを呼んだ後だけ |
| 公開範囲 | URLを知っている人は誰でも開けることを添えている |
