# 最小トレース: タイトルだけを変える（全置換更新）

更新は全項目必須の全置換なので、**詳細取得の返り値をそのまま載せ直す**のが唯一安全な組み立て方。ここを省くと、エラーにならずにファイル本体や OGP 画像が失われる。値はすべて架空。

---

## ケース1: PDF のタイトルを変える

### ユーザー

> 「受講の手引き」のタイトルを「受講ガイド 2026冬」に変えて

### 1. 対象を特定する

`getCreatorMaterials` → 該当が1件（ID `903`、種別 PDF）。**種別が分かるのでこの先は PDF のツールを使う**（動画・画像のツールに渡すと 404）。

### 2. 詳細を取得する（省略できない）

`getCreatorMaterialFile` → `{ "pathParams": { "id": 903 } }`

返り（抜粋）:

```
title:         "受講の手引き"
moshMediaId:   "media-8f2c..."
fileSizeBytes: 4194304
```

### 3. 提示して承認を得る

> 「受講の手引き」のタイトルを「受講ガイド 2026冬」に変更してよいですか。**まだ変更していません。**（ファイル本体はそのままです）

### 4. 更新する

`patchCreatorMaterialFile`

```json
{
  "pathParams": { "id": 903 },
  "bodyParams": {
    "title": "受講ガイド 2026冬",
    "moshMediaId": "media-8f2c...",
    "fileSizeBytes": 4194304
  }
}
```

**`moshMediaId` と `fileSizeBytes` は手順2の値をそのまま。** ここを省く／別の値にすると、ファイル本体が別物に差し替わるか、表示できないファイルになる（どちらもエラーにならない）。

### 5. 報告

> タイトルを「受講ガイド 2026冬」に**変更しました**。共有URLは変わっていません。

---

## ケース2: 動画のタイトルを変える（OGP画像を消さない）

### 1〜2. 対象を特定して詳細を取得する

一覧で種別（動画・ID `901`）を確かめてから `getCreatorMaterialVideo` → `{ "pathParams": { "id": 901 } }`

返り（抜粋）:

```
title:                "体験レッスン紹介"
ogpImageMoshMediaId:  "media-ogp-901"
```

### 3. 提示して承認を得る

> 動画「体験レッスン紹介」のタイトルを「体験レッスン紹介（2026年版）」に変更してよいですか。**まだ変更していません。**（サムネイル画像はそのまま残します）

**ケース1と同じく、ここで止まる。** 本体を触らない更新でも承認は省かない。

### 4. 更新する

`patchCreatorMaterialVideo`

```json
{
  "pathParams": { "id": 901 },
  "bodyParams": {
    "title": "体験レッスン紹介（2026年版）",
    "ogpImageMoshMediaId": "media-ogp-901"
  }
}
```

**`ogpImageMoshMediaId` を省くと必須項目不足で拒否され、空文字にすると OGP 画像が消える。** タイトルだけ変えたいなら取得値をそのまま渡す。

### 5. 報告

> タイトルを「体験レッスン紹介（2026年版）」に**変更しました**。サムネイル画像と共有URLは変わっていません。

---

## この例が示していること

| 論点 | この例での扱い |
|---|---|
| 全置換 | 変えない項目も詳細取得の値を必ず載せ直す |
| 種別の確定 | 一覧で種別を確かめてから種別ごとのツールを使う（取り違えは 404） |
| 空文字の意味 | 動画の OGP は空文字＝削除。維持したいなら取得値をそのまま |
| 承認 | 本体を触らない更新なので、`patch` の直前で1回止める |
| 報告 | 変更した項目と、変わっていないもの（共有URL）を明示する |
| 提示規約 | 内部の識別子をユーザー向け文面に出していない |
