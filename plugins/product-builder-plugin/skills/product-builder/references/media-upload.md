# 画像のアップロード手順（商品画像・申し込み後の流れの画像・サンクスページのバナー画像）

**いつ読むか**: 手元の画像ファイルを商品画像・申し込み後の流れ・サンクスページのバナーに付けたいとき。

`imageIds` / `steps[].imageId` / `bannerMediaId` に入れる画像 ID は、この手順で発行した `moshMediaId` を使う。**手順の順番は入れ替えられない。**

## 前提: ファイルを送れる環境か

MCP が発行するのはアップロード先の URL まで。ファイル本体をその URL へ HTTP PUT するのはクライアント側の仕事になる。

- シェルを実行できる環境（Claude Code 等）で、ファイルが手元にある → 下の手順で最後まで進める
- シェルを実行できない環境、またはファイルが手元に無い → 画像なしで作成・更新し、画像は管理画面で付けてもらう。画像以外の項目はこのスキルで進めてよい

## 既存の画像を使うとき

アップロード済みの画像を一覧・検索するツールは無い。既存の画像を使えるのは次の 2 通りだけ。

- 商品にいま付いている画像を残す・並べ替える → `getCreatorProduct` で読んだ `imageIds` / `steps[].imageId` をそのまま使う
- サンクスページのバナーをそのまま残す → `bannerMediaId` を省略する（省略＝維持）

それ以外の既存画像は、ユーザーから ID を受け取るか、手元のファイルを下の手順でアップロードし直す。**それらしい ID を作らない。**

## 手順

1. **聞くこと**: ファイルの置き場所、どこに使うか（商品画像・申し込み後の流れの何番目か・サンクスページのバナー）。形式は JPEG・PNG・WebP のどれか
2. **発行**: `postMeMediaUploadUrls` を呼び、`moshMediaId` と `uploadUrl` を受け取る。1 ファイルにつき 1 回発行する

   | パラメータ | 必須 | 値 |
   |---|---|---|
   | `name` | ○ | 拡張子つきのファイル名（例: `cover.png`） |
   | `type` | ○ | 拡張子から選ぶ。JPEG は `imageJpeg`、PNG は `imagePng`、WebP は `imageWebp` |
   | `isPrivate` | — | **送らない（省略＝公開）**。商品画像・バナーは公開ページと完了メールに出るので、`true` にすると表示できない |

   `type` には文書やアーカイブの種類もあるが、ここでは画像 3 種だけを使う。`imageHeic` / `imageHeif` は画像として扱われないので使わない（HEIC の写真は JPEG か PNG に変換してから送る）
3. **PUT**: 発行から **15 分以内**に送る。`Content-Type` ヘッダーは付けなくてよい

   ```bash
   curl -sS -X PUT -T "<画像ファイル>" "<uploadUrl>" -o /dev/null -w '%{http_code}\n'
   ```

   200 番台なら成功
4. **紐付け**: `moshMediaId` を ID として使う
   - 商品画像 → `postCreatorProduct` / `patchCreatorProduct` の `imageIds`。**更新では既存の ID を含めた全件を送る**（置き換えのため。SKILL.md 手順 3）
   - 申し込み後の流れの画像 → `patchCreatorProduct` の `steps[].imageId`。全ステップを送る
   - サンクスページのバナー → `patchCreatorProductPlanSettingsThanks` の `bannerMediaId`。`content` は現在値をそのまま送る
5. **読み戻し**: `getCreatorProduct` / `getCreatorProductPlanSettingsThanks` で、送った ID が入っていることと、残すはずの画像が消えていないことを確かめる

アップロード後の画像の処理（変換）が終わったかを確かめるツールは無い。公開ページでの見え方を確かめたいときは、商品が公開中なら `publicUrl` を案内する。

## 失敗したとき

| 状態 | 対応 |
|---|---|
| PUT が 200 番台以外・15 分を過ぎた | 手順 2 の発行からやり直す |
| 「指定された画像が見つかりません。」で拒否された | 自分がアップロードした画像でない、存在しない、画像ではない種類で発行した、のいずれか。PUT が成功していたか・`type` が画像 3 種かを確かめ、手順 2 からやり直す |

使わなかった画像を MCP から消す手段は無い。商品やバナーに指定しない限り、ゲストには見えない。

## 守ること

- **`uploadUrl`・`moshMediaId` をユーザーに見せない。** 「商品画像を追加しました」のように結果で伝える
- **`isPrivate: true` で発行しない。** 公開ページ・完了メールに表示できなくなる
