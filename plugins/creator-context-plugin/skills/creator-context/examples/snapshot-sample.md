## この実例から学ぶこと

- 要約は「商品（買い切り/サブスク）」「集客の装置（LP/WF/LINE）」「売上（金額と、月100万円超などの数字で言える山）」「規模（顧客・コンタクト）」「SNS」の5テーマで、1行1テーマで書く。評価語（好調・不調）や「ローンチ型」のような解釈は書かない。取れない物は要約に入れず末尾の節に書く
- 顧客総数 1,420 と商品の購入件数 212、顧客検索の「サブスク継続中 41」と購読者の「active 36 + pastDue 2」は、それぞれ母集団・集計元が違う。矛盾ではないので数字を無理に合わせない
- SNS のフォロワー数は取りに行かず、ユーザー申告があるものだけ「（申告）」付きで書く。無いものは「-」
- 0件（ウェビナー）は該当セクションに「0」と書くだけで、「取得できなかった項目」には載せない。取得失敗（ツール不在・エラー）だけをそこに書く
