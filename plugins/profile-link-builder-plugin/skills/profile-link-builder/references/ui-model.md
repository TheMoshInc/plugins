# 画面とデータの対応（ユーザー向け用語）

裏取り元: 管理画面「プロフィール」の画面のラベル。ラベルを確認できなかったものは「未確認」と書く。

## 管理画面の構成

クリエイター管理画面「プロフィール」。編集モードでカード（ウィジェット）をドラッグ&ドロップで並べ替えられ、保存時に表示順が更新される。

- **プロフィール／ヘッダー**: 「プロフィールセクションを編集」（名前・キャッチコピー・自己紹介・アイコン）、「ヘッダーを編集」（ヘッダーデザイン・プロフィール画像・SNSリンク）
- **タブ**: 「リンク」（コンテンツ）/ 「サービス」/ 「レビュー」（感想レポート）/ 「メディア」（ギャラリー）

## ユーザーに見せる言葉 ↔ 内部名

| ユーザーに言う | 内部（ユーザーには出さない） |
|---|---|
| プロフィール（名前・キャッチコピー・自己紹介・アイコン） | `getProfileLinkProfile` / `iconPictureId` |
| ヘッダーデザイン | `templateId`（`header-1`〜`header-6`）。**こちらから `header-N` を出さない**（画面上の名称は未確認）。ユーザーが自分で `header-3` などと指定した場合は、その呼び方に合わせてよい |
| ヘッダーの背景画像・ぼかし・文字色 | `imageId` / `imageBlur` / `textColor` |
| ヘッダーのSNSアイコン | ヘッダーSNSリンク（`snsType` + `url`） |
| テーマ（背景色／グラデーション／背景画像） | `backgroundColor` / `gradient` / `imageUrl`・`imageId` |
| メディア（ギャラリー）の画像・動画 | ギャラリー項目 |
| 「リンク」タブのカード | コンテンツ（`type`） |
| 見出し | `heading` |
| 画像 | `image` |
| ウェブリンク | `link` |
| マップ（地図） | `map` |
| SNSリンク（カード） | `sns` |
| 動画 | `video` |
| サービス購入導線 | `service` |
| 特典 | `benefit` |
| カードの大きさ（リンクタブ） | `layout`（`small` = 小サイズ（正方形）/ `horizontal` = 横長サイズ（2×1）/ `vertical` = 縦長サイズ（1×2）/ `large` = 大サイズ（2×2）） |
| サービスカードの大きさ（小・中・大） | `cardSize`（`SMALL` / `MEDIUM` / `LARGE`） |
| 表示/非表示 | `isVisible` |
| 表示順 | `displayOrder`（0始まり。ユーザーの「1番目」= `0`） |

## サービス／レビュータブ

- **サービス**: 商品/サービス設定側で用意した販売対象を、プロフィールリンク上でカード表示するもの。本スキルが扱うのは**カードの表示設定だけ**（表示/非表示・表示順・カードサイズ）。サービス自体の名前・価格・説明・公開設定は別（`product-navigator` / `product-builder`）。表示設定は「表示中のサービス」「追加可能なサービス」の2区分のシートで切り替える画面もある
- **感想レポート（レビュー）**: 顧客が投稿した感想。表示設定は表示/非表示と表示順だけで、カードサイズは無い。編集画面では目玉アイコンで表示/非表示を切り替える

## 画面操作との対応（本スキルでできること）

| 画面上の操作 | ツール |
|---|---|
| 自己紹介などの編集 | `patchProfileLinkProfile` |
| ヘッダーデザイン／背景の変更 | `patchProfileLinkHeader` |
| ヘッダーのSNSアイコンの追加・変更・削除・並べ替え | [header-sns-gallery-media.md](header-sns-gallery-media.md) |
| テーマの変更 | `patchProfileLinkTheme` |
| メディアの追加・並べ替え・削除 | `putProfileLinkGalleryItems` |
| リンクタブのカードの追加・編集・削除・大きさ変更・並べ替え | [content-blocks.md](content-blocks.md) |
| サービスカードの大きさ・表示/非表示・並べ替え | [service-report-tools.md](service-report-tools.md) |
| レビューの表示/非表示・並べ替え | 同上 |
| サービス購入導線・特典カードの追加・編集 | **対象外**（ツールなし。管理画面を案内） |
| サービス・感想レポート自体の新規作成・削除 | **対象外**（ツールなし） |
